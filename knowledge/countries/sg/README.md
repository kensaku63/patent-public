## 実務への適用（Agentの整理）
SG案件では、出願形態・公開履歴・海外出願許可の要否を確認し、根拠資料と対象条件を記録する。ソフトウェア・AIの起案では課題、技術的構成、入出力、効果の関係を明記し、元資料にない技術を創作しない。料金や期限はカードの確認時点の情報を出発点に、案件に使う前に再確認する。

## 旧メモからの扱い
過去のSGメモの一般論点を公式情報で確認できた範囲に絞って保存した。所有者の居住地、件数、Projectの戦略は移していない。法令本文、グレースピリオドの詳細、延長の適用条件、クレーム形式の細則は今回の確認対象外または未取得であり、旧メモの断定を復元していない。

料金表のPF10には旧メモの「全検索・審査で15項超加算」を一律に適用しない。Guidesページの更新日とPDF本文のOct 2023表示を区別した。全資料の全文保存・全条項の検証ではなく、公式リンクと指定範囲の自作要約を収録している。
