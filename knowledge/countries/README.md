# 国別の公式資料

国コードごとに、公式出典と確認内容をこのリポジトリへ保存する。現在の収録国は [SG（シンガポール）](sg/README.md)。未収録国は調査時に同じ構造で追加する。

## 保存の手順
1. 対象国の特許庁、政府法令サイト、WIPOなどの一次情報を調べる。既存の国別メモを先に読む。
2. `knowledge/countries/<国コード>/sources/<資料名>.md` に資料名、発行機関、公式URL、資料の版・更新日、確認日、確認した章・段落、要点、未確認事項を保存する。[資料カード](source-template.md)を使う。
3. 国別READMEから資料カードへリンクし、案件横断で使える知見を整理する。公式記載の要約とAgentの実務的解釈を明確に分ける。
4. 原文を全文転載せず、短い必要最小限の引用または自分の言葉の要約を保存する。公開版にはPDF等のバイナリ、認証情報、案件データを入れない。公式PDFはリンクと章・ページで追跡可能にする。権利が許す原文テキストの保存が必要な場合も、対象範囲と利用条件を明記する。
5. ページ更新日、PDF内部の版、施行日、確認日は別の項目として扱う。取得失敗は日付を記録し、本文確認済みにしない。
6. 料金・期限・様式・法的判断に使う前に最新情報を再確認する。改訂時は旧版との相違、影響範囲、確認履歴をカードへ追記する。古い確認日だけを新しくしない。
7. 国別の一般知識はAgentリポジトリへ保存する。個別出願人、住所、未公開発明、認証・支払・提出記録は利用者指定の非公開Projectへ置く。

利用者が国別知識の蓄積を依頼している場合、調査タスクの一部としてカードを更新する。commit・push・公開はその時点の権限と環境の契約に従い、保存したことだけで配布済みとは報告しない。
