# 成果物の空欄テンプレート

すべて第一稿。実際の案件データは利用者が指定した非公開の保存先に置く。各成果に対象範囲、作成日、根拠、未確認事項、次の判断を付ける。

## 発明提案書
- 名称 / 対象国 / 発明者・権利帰属（未確認可）
- 解決課題と従来手法
- 核となる構成・処理と、従来との差分
- 実装根拠: ファイル・シンボル・該当箇所
- 技術的効果: 測定済み / 期待 / 未検証を分ける
- 実施例、代替構成、適用条件
- 公開履歴と根拠、既知文献、追加調査事項

- 独立項: <主体>が<入力>を受け、<核となる処理と構成>により<出力>を得る。
- 従属項: <引用項>の<構成>に<具体的限定>を加える。
- 各請求項の要素について、実施形態と図面の根拠箇所を対比する。
- 数値や実験結果を創作しない。未実施の例はその旨を明示する。
