# 図面案の点検

図面案は構成図、フローチャート、シーケンス図、データ構造図から発明の説明に必要なものを選ぶ。

1. 構成要素に一貫した符号を付け、本文・請求項・符号一覧と照合する。
2. 各図に番号と説明を付ける。処理順、分岐、主体、関係線に抜けがないか確認する。
3. Mermaid等のソースは下書きとする。正式図面は対象国の最新公式要件に沿って清書する。
4. 変換した図では、元ソースのノード・エッジと出力を対比し、欠落、重なり、切れ、構文の文字残りを検査する。
5. PDFを作る場合は全ページをレンダリングし、縮小時の可読性も目視確認する。ファイルが開けるだけでは合格にしない。
6. 図面変更が発明の開示内容を変える場合は、その変更点を明記して専門家へ確認する。

このパッケージは正式図面生成スクリプトや提出用PDFを含まない。
