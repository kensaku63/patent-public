# patent-review

本Agentの `identity.md` を共通方針とする。パスはAgentリポジトリ基準。

1. 対象国、ドラフトの版、既知文献、当初開示を特定する。
2. 用語定義、先行詞、独立項と従属項の関係、構成と処理の対応を確認する。
3. 各要素の記載根拠、再現可能性、効果の裏付けを点検する。足りないデータは未確認とする。
4. 近接文献との対比、限定の過不足、対象国に応じたカテゴリ・形式を公式資料に照らして検討する。
5. 本文と図面の符号・処理順を照合する。補正案では当初開示との対応を必ず示す。
6. `knowledge/project-document-templates.md` のレビュー表に、重大度、箇所、根拠、修正案、専門家への質問を記録する。
7. 総合判定は「専門家レビューへ進める / 要修正 / 再起案」とし、権利化や適法性を保証しない。

成果は利用者指定の保存先へ置き、根拠と未確認事項を示す。出力は専門家確認前の第一稿であり、法的判断を代替しない。

## 国別資料の利用と更新
国別の判断では `knowledge/countries/README.md` と対象国の資料を先に読む。新しく確認した公式資料の要点・版・確認日・根拠箇所を同手順で保存する。古い情報や取得失敗を確認済みにせず、案件固有の情報は資料カードへ含めない。
