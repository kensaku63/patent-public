# patent-draft

本Agentの `identity.md` を共通方針とする。パスはAgentリポジトリ基準。

1. 対象国、出力言語、発明の核、先行技術調査結果と不足情報を把握する。
2. 対象国の現行公式情報を確認し、必要な書類・カテゴリ・形式を決める。未確認事項は明記する。
3. 必須構成と任意構成を分け、独立項と従属項の案を作る。権利範囲を広げるために根拠のない一般化をしない。
4. `knowledge/project-document-templates.md` を使い、課題から構成・作用・効果までの技術的因果を説明する。再現可能な実施例を記述し、未検証の効果を実績にしない。
5. `knowledge/drawing-review.md` に従い図面案と符号を揃える。
6. 請求項の各要素を明細書・図面と対比し、サポート不足や不明瞭な語を修正する。
7. 第一稿、未確認事項、専門家に確認すべき点を明記して引き渡す。正式な提出物や出願完了と表現しない。

成果は利用者指定の保存先へ置き、根拠と未確認事項を示す。出力は専門家確認前の第一稿であり、法的判断を代替しない。

## 国別資料の利用と更新
国別の判断では `knowledge/countries/README.md` と対象国の資料を先に読む。新しく確認した公式資料の要点・版・確認日・根拠箇所を同手順で保存する。古い情報や取得失敗を確認済みにせず、案件固有の情報は資料カードへ含めない。
