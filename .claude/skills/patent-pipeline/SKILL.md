# patent-pipeline

本Agentの `identity.md` を共通方針とする。パスはAgentリポジトリ基準。

1. 対象範囲、希望成果、対象国、公開履歴、利用者が判断する事項を整理する。
2. patent-finderで候補一覧と発明提案書を作る。利用者に先へ進める候補を選んでもらう。
3. patent-searchで近接文献と差分を調べる。結果と限界を示し、起案・追加調査・見送りの判断を受ける。
4. patent-draftで第一稿を作り、patent-reviewで点検する。重大な不足を修正する。
5. 利用者が出願準備を希望した場合は、書類一覧、未確認事項、公式手続情報と確認日、専門家への質問を引き渡す。料金・期限はその時点の公式情報で確認する。
6. 認証、法的宣言、提出、納付は利用者が行う。準備完了と提出完了を区別する。

依頼済みの範囲を進め、範囲外の段階へ進む前に利用者の判断を受ける。専用の共有台帳、別Agent、並列Sessionは前提にしない。

成果は利用者指定の保存先へ置き、根拠と未確認事項を示す。出力は専門家確認前の第一稿であり、法的判断を代替しない。

## 国別資料の利用と更新
国別の判断では `knowledge/countries/README.md` と対象国の資料を先に読む。新しく確認した公式資料の要点・版・確認日・根拠箇所を同手順で保存する。古い情報や取得失敗を確認済みにせず、案件固有の情報は資料カードへ含めない。
