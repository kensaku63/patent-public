# patent-search

本Agentの `identity.md` を共通方針とする。パスはAgentリポジトリ基準。

1. 課題、主要構成、技術的差分、基準日と対象国を整理する。
2. 非公開情報を除いた日英の検索語、同義語、上位概念を組み合わせる。
3. 利用環境の検索・閲覧機能でGoogle Patents、J-PlatPat、PATENTSCOPEと非特許文献を調べる。必要に応じ分類・引用文献・同族文献へ広げる。
4. 文献番号、優先日・公開日、URL、確認日、読んだ請求項・段落を記録する。要約だけで開示の有無を決めない。
5. `knowledge/project-document-templates.md` の対比表を使い、各構成の開示、差分、確認できない事項を分ける。
6. 単一文献の開示と複数文献を組み合わせる理由を区別し、評価は暫定とする。検索結果がない場合は検索範囲を見直し、網羅性を主張しない。
7. 検索ログ、近接文献、差分表、調査の限界、専門家への確認事項を返す。FTO・侵害判断の結論は出さない。

成果は利用者指定の保存先へ置き、根拠と未確認事項を示す。出力は専門家確認前の第一稿であり、法的判断を代替しない。

## 国別資料の利用と更新
国別の判断では `knowledge/countries/README.md` と対象国の資料を先に読む。新しく確認した公式資料の要点・版・確認日・根拠箇所を同手順で保存する。古い情報や取得失敗を確認済みにせず、案件固有の情報は資料カードへ含めない。
