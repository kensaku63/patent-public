# Patent Research & Drafting

ソースコードや設計資料から特許候補を整理し、先行技術調査、発明提案書、出願ドラフト、レビューを支援する日本語Agentです。出力は専門家確認前の第一稿であり、権利取得や調査の網羅性を保証しません。

## 使い始める
1. 読み取りを許可するリポジトリまたは資料と、欲しい成果を指定します。
2. 対象国、公開済みの範囲と日付、既知の先行文献を伝えます。不明な項目は未確認として扱います。
3. 例: 「このリポジトリを読み取り、技術的な工夫を3件まで整理してください。コードの根拠と未確認事項を付け、今回は発明提案書までにしてください。」
4. 出力先を指定します。aachatでは現在のProjectの文書契約に従い、それ以外では利用者指定のローカル文書を使います。元の著者の環境やProjectは不要です。

## 同梱内容
`identity.md`、5つのSkill（発掘・調査・起案・レビュー・統合）、発明提案書などの空欄テンプレート、図面の点検手順を含みます。過去案件・記憶・実在する発明のサンプルは含みません。

## 環境と外部サービス
- 必須Pluginはありません。実行モデル・認証は利用先の環境で設定してください。
- コード調査には読み取り・ファイル検索、先行技術調査にはWeb検索・ページ閲覧機能が必要です。本パッケージは特定のツール名やブラウザ自動化CLIに依存しません。
- 調査時に利用可能な公開検索先: Google Patents、J-PlatPat、WIPO PATENTSCOPE。ログイン・利用条件への同意が必要な場合は利用者が行います。アクセスできない情報は未取得と報告します。
- 外部送信は機密を除いた検索語を基本とし、非公開データの送信は利用者と所属組織の許可を要します。認証情報は利用先の秘密情報管理機構で扱い、このリポジトリに保存しません。
- 出力はMarkdownの文書・図面案です。提出用PDF生成、IPOS入力、電子出願、決済の自動化は同梱しません。正式図面の作成には利用者が選んだ製図・PDF環境が別途必要です。
- 国別の公式資料カードを `knowledge/countries/` に保存しています。SGの確認済み要約を収録していますが、恒久的な最新版を保証するものではありません。案件ごとに各国庁の公式資料を確認し、出願前に専門家のレビューを受けてください。

## 公開範囲
会社固有ルール、顧客情報、個別出願記録、作者のローカルパス、固定の担当Agent、専用スクリプト、継続実行や自動pushの指示を除いています。ライセンスの追加付与はこの準備で行っていません。
